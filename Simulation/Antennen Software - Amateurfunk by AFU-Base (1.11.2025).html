MMANA-GAL▲

Ein Programm zur Antennenanalyse

MMANA-GAL ist ein Werkzeug zur Antennen-Analyse, das auf der mit MININEC Version 3 eingeführten Momentenmethode basiert.

MMANA-GAL Basic ist frei. Alexander Schewelew DL1PBD, Igor Gontcharenko DL2KQ und Makoto Mori JE3HHT haben das Copyright von MMANA-GAL.

Das Programm kann frei fur private Zwecke genutzt werden.
