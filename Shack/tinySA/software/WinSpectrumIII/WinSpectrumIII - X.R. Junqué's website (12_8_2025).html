The official tinySA firmware executes .CMD scripts asynchronously. This means that sequences such as 'start sweep → wait → save image' may not always work reliably. The TEST7.2 XJ firmware below is an experimental build that provides fully synchronous .CMD execution, including the ability to save .CMD files directly on the tinySA. It also supports transferring files between the tinySA and the PC via USB. This is not an official tinySA firmware and is provided without any guarantee.
