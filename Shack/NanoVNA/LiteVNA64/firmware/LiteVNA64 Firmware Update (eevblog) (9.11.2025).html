Re: LiteVNA64 Firmware
« Reply #3 on: April 08, 2022, 07:40:33 pm »
You should have the NanoVNA App installed and the latest firmware file downloaded on your PC.

Start the app and leave the LiteVNA64 off. Connect the LiteVNA64 to the PC via USB. Power up the LiteVNA64 while holding down the thumbwheel. Then drop down the connection port list on the app and select the correct COM port the LiteVNA64 is connected to. A dialog box should pop up and ask if you want to upgrade the firmware. Click the file folder icon on the top edge of the dialog box and select the firmware file you already downloaded and voila.

Also, you should join the Groups.io beta software thread [nanovna-beta-test] as many changes do not automatically make their way to the Google drive hosted by the hardware maker. The beta version I am using currently is v1.2.08 which is here https://drive.google.com/file/d/1WshkOyHRxJBzSbyC8ytuaBNpTQYVA483/view?usp=sharing

Good luck.
